# CareerGraph AI — Frontend

React 19 + Vite client for CareerGraph AI. The full project overview, architecture, API
documentation, testing evidence and honest limitations live in the [root README](../README.md).

## Local development

Start the backend on `http://127.0.0.1:8000`, then:

```bash
npm install
npm run dev
```

The Vite dev server runs at `http://localhost:5173` and proxies `/api` to the backend.

## Commands

```bash
npm run dev         # Vite dev server
npm run test        # Vitest (run once)
npm run test:watch  # Vitest watch mode
npm run lint        # oxlint
npm run build       # production build into dist/
npm run preview     # preview the production build
```

## Structure

- `src/pages/` — route-level screens, including the Phase 7 advisor and the catch-all 404.
- `src/components/` — shared UI (navigation, icons, forms, page headers, empty/loading states,
  dashboard cards).
- `src/context/`, `src/hooks/` — authentication state and the `useAuth` hook.
- `src/services/api.js` — the single HTTP layer and FastAPI error normalisation.
- `src/index.css` — design tokens, layout, component styles and responsive/reduced-motion rules.
- Colocated `*.test.jsx` files — Vitest + Testing Library.

`dist/` is generated by the build and is gitignored. Visuals are CSS/SVG, not remote stock
imagery.
